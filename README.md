# Biomarkers_Male_CartilageBoneProcessing
M-files for processing Biomarkers Male knee cartilage and bone OsiriX CSV files.

See: Pius AK, Beynnon BD, Fiorentino N, Gardner-Morse M, Vacek PM, DeSarno M, Failla M, Slauterbeck JR, Sturnick DR, Argentieri EC, Tourville TW. "Articular cartilage thickness changes differ between males and females 4 years following anterior cruciate ligament reconstruction"  J Orthop Res 40(1):65-73, 2022. doi: 10.1002/jor.25142. PMID: 34288090

M-files for generating femur, patella, and tibia bone based coordinate systems and bone and cartilages surfaces from OsiriX CSV files.
